Lesson 1: TypeScript setup + Type inference


FileCreation:

	app.ts(eg)

ForCompile:

	tsc app.ts (it converts the typescript to js)

ForRun:

	node app.js



WorkFlow :


app.ts  (You write TypeScript)
   |
   | tsc app.ts
   ↓
app.js  (Generated JavaScript)
   |
   | node app.js
   ↓
Output

=> Truthy and Falsy

 In javaScript, every value is automatically treated as, 
 Truthy - acts as True
 Falsy - acts as False

** important is FalsyValues **
 
> false
> 0
> -0
> 0n
> ""
> null
> undefined
> NaN	

 ** Truthy Values **

> "hello"
> "0"
> "false"
> 1
> -5
> []
> {}
> true

 Example of both Truthy and Falsy

 <  let values = [
  false,
  0,
  -0,
  0n,
  "",
  null,
  undefined,
  NaN,
  "Hello",
  "0",
  "false",
  10,
  -5,
  [],
  {},
  true
];

for (let i = 0; i < values.length; i++) {
  if (values[i]) {
    console.log(values[i] + " → Truthy");
  } else {
    console.log(values[i] + " → Falsy");
  }
}   >

Op - 

   false → Falsy

0 → Falsy
 → Falsy

=> For Of

--------normal way of for---------

let fruits = ["Apple", "Mango", "Orange"];

for (let i = 0; i < fruits.length; i++)
{
    console.log(fruits[i]);
}

--------for of --------

let fruits = ["Apple", "Mango", "Orange"];

for (let fruit of fruits)
{
    console.log(fruit);
}

same op - Apple Mango Orange

---> it works only Array, String, Maps, Sets. Not used in normal object.

********🎯 Easy Interview Answer

for...of loop is used to iterate through values of an iterable like arrays and strings. It directly gives each value without using index.  ***********

=> For in

let student =
{ name: "Jeeva", age: 21, dept: "CSE" };//key(name, age, dept) and value(Jeeva, 21, CSE)

for (let key in student)   // key define variable from person

    console.log(key + " : " + student[key]);
}

age : 21
dept : CSE
